## Commands I Learned

| Command | Meaning | Purpose |
|---|---|---|
| `pwd` | Print Working Directory | Shows my current folder |
| `ls` | List | Shows files and folders |
| `whoami` | Who am I? | Shows my current username |
| `sudo apt update` | Update package lists | Refreshes available software information |

## What I Learned
- Linux commands help me interact with the operating system.
- Directories are folders used to organize files.
- The terminal lets me control Linux using text commands.
- `sudo` allows authorized administrative actions.
