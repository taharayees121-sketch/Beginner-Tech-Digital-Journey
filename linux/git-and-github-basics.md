# What is Git
Git is a version control system.
It Tracks changes made to files and projects.

# What is Github
GitHub is an online platform that hosts Git repositories.

## Git Commands Practised

git --version : Check Git version

git config : Configure Git identity

git clone : Download a repository

pwd : : Display current directory.

ls -la : List files and hidden folders.

cat : Read file contents.


## Important Git Concepts

- Repository: A project tracked by Git.
- Commit: A saved snapshot of changes.
- Push: Upload local commits to GitHub.
- Pull: Download and integrate remote changes.
- Clone: Create a local copy of a remote repository.
