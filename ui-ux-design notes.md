# UI/UX Design Notes

**Date:** October 29, 2026  
**Level:** Beginner

## 1. What is UI?
UI stands for User Interface. It includes the visual elements of an app or website, such as:
- Buttons and icons
- Colors and typography
- Layouts and spacing
- Images and navigation menus

## 2. What is UX?
UX stands for User Experience. It focuses on how easy, useful, and enjoyable a product is to use.

Examples:
- Simple navigation
- Easy checkout process
- Clear product information
- Helpful error messages and feedback

## 3. UI vs UX

| UI | UX |
|---|---|
| Focuses on visual design | Focuses on the overall experience |
| Colors, buttons, fonts | Usability, navigation, user needs |
| Makes the interface clear | Makes the product easy to use |

## 4. Important Design Principles
- **Visual hierarchy:** Make important information stand out.
- **Alignment:** Keep elements organized.
- **Spacing:** Leave enough space between elements.
- **Contrast:** Make text easy to read.
- **Consistency:** Use similar styles throughout the app.
- **Feedback:** Show users when an action succeeds or fails.

### Improvements to explore
