### Q1. Linux File Permissions
Command: chmod 640 notes.txt

What permissions does the owner receive?

A. Read and write
B. Read only
C. Read, write and execute
D. Write only

**Answer: A — Read and write**

Explanation: 6 = 4 (read) + 2 (write).

### Q2. Linux Search
What does grep -r 'error' /var/log/ do?

A. Delete error messages
B. Search recursively for error
C. Replace error with success
D. Display only the last error

**Answer: B**

Explanation: -r searches recursively through directories.

### Q3. Networking Troubleshooting
A computer can ping 8.8.8.8 but cannot open google.com. What is the likely issue?

A. Monitor disconnected
B. DNS resolution problem
C. Keyboard faulty
D. No IP address

**Answer: B**

Explanation: IP connectivity works, but domain name resolution may be failing.

### Q4. IP Addressing
A device has IP 192.168.1.25/24. What is its network address?

A. 192.168.1.1
B. 192.168.1.25
C. 192.168.1.0
D. 192.168.0.0

**Answer: C**

Explanation: /24 corresponds to subnet mask 255.255.255.0.

### Q5. AWS Networking
Which AWS service creates an isolated virtual network?

A. Amazon S3
B. Amazon VPC
C. AWS IAM
D. Amazon CloudWatch

**Answer: B — Amazon VPC**

Explanation: VPC provides an isolated virtual network for AWS resources.

### Q6. AWS Security
An EC2 instance needs access to S3 without permanent access keys. What should you use?

A. Hardcoded access key
B. Root account password
C. IAM role attached to EC2
D. Disable S3 security

**Answer: C**

Explanation: IAM roles provide temporary credentials to AWS services.

### Q7. UI/UX Design
Users repeatedly abandon a checkout form. What should you do first?

A. Add animations
B. Investigate usability through user testing
C. Change the logo
D. Increase form fields

**Answer: B**

Explanation: User testing identifies usability problems and checkout friction.

### Q8. Digital Marketing
Which metric measures the percentage of visitors who purchase?

A. Bounce rate
B. Conversion rate
C. Impressions
D. Domain authority

**Answer: B — Conversion rate**

Explanation: It measures the percentage of visitors completing a desired action.

### Q9. Git and GitHub
You committed changes locally, but GitHub has newer commits. What should you generally do before pushing?

A. Delete the repository
B. Fetch and integrate remote changes
C. Run git init again
D. Delete local commits

**Answer: B**

Explanation: Integrate remote changes, resolve conflicts if necessary, then push.

Example:
git pull --rebase origin main

### Q10. Linux Troubleshooting
Which command identifies filesystems running out of disk space?

A. free -h
B. df -h
C. whoami
D. uname -a

**Answer: B — df -h**

Explanation: Displays filesystem disk usage in human-readable format.
